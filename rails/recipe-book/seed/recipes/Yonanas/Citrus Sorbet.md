# Citrus Sorbet

## Ingredients
- 1 C frozen seedless orange segments
- 1/4 C frozen grapefruit
- 1/2 cup frozen seedless lemon segments

## Instructions
1. Add 1/2 cup frozen orange segments.
2. Insert 1/4 C frozen grapefruit.
3. Add 1/4 cup frozen lemon segments.
4. Alternate remaining ingredients.

## Shopping List
- 1 C frozen seedless oranges
- 1/4 C frozen grapefruit
- 1/2 cup frozen seedless lemons
