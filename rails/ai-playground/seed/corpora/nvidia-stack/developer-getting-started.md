# Getting started as an NVIDIA developer or partner

NVIDIA gives developers a clear on-ramp from "try it in a browser" to "self-host in production," which
is the exact path a developer-relations engagement helps partner teams travel.

build.nvidia.com is the central hub to browse thousands of AI models and try or preview NIM
microservices from a web UI, and to reach the NVIDIA API Catalog of hosted preview endpoints along
with one-click Blueprints for RAG and agentic AI. It is the fastest way to evaluate a model or a
reference workflow with no local setup. Members of the NVIDIA Developer Program get free access to NIM
API endpoints for unlimited prototyping, powered by DGX Cloud, so a developer can build against the
OpenAI-compatible API before deciding to self-host.

The NGC Catalog is a curated set of GPU-optimized software for AI, HPC, and visualization: containers,
pretrained models, Helm charts, and domain SDKs, plus documentation, code samples, and Jupyter
notebooks. It is where a team pulls the validated artifacts to run NVIDIA software in their own
environment.

The NVIDIA Developer Program is free to join and is designed to get developers up to speed with
training and early technology access. Membership includes access to NIM and Omniverse, the CUDA
Toolkit and Nsight developer tools, Deep Learning Institute courses, developer forums with expert
help, the NGC catalog, and access to GTC. It is the front door to NVIDIA's developer ecosystem.

The NVIDIA Deep Learning Institute (DLI) provides hands-on training in AI, data science, and
accelerated computing, delivered as self-paced online courses, live instructor-led workshops,
certifications, and downloadable teaching kits for educators. Labs run on GPU-accelerated cloud servers
using NGC containers, and select courses grant a shareable NVIDIA certificate of competency. DLI tracks
span generative AI and LLMs, accelerated computing, data science, graphics and simulation, AI
infrastructure, and industry verticals such as healthcare, robotics, and autonomous vehicles.

For a systems integrator, this on-ramp is the raw material of enablement. A developer-relations
engagement curates it into a specific path for a partner: point their developers at the right hosted
NIM to prototype, hand them a blueprint and sample code as a starting point, pair it with the relevant
DLI training, and support the move to a self-hosted, NVIDIA AI Enterprise deployment. Turning that into
a reusable partner accelerator is how one enablement effort compounds across a GSI's client base.
