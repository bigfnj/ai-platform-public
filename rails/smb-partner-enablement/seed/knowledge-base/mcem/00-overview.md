## What belongs in this collection

The Microsoft Customer Engagement Methodology: the stages a partner-led opportunity moves
through, what has to be true to exit each stage, which artifacts are produced, and how the
partner's motion maps onto the seller's. One file per stage reads better than one long file,
because each stage then earns its own citation.

## How the assistant should use it

A partner asking "what do I need before I can move this to the next stage" should get the
exit criteria for their current stage and nothing else. Keep exit criteria phrased as
checkable statements rather than aspirations, so the model can quote them directly.
