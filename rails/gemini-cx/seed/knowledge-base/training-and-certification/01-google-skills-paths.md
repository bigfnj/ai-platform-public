# Google Skills learning paths for GECX

> Source: skills.google/paths/3180; partner.skills.google paths 521, 522, 523, 484, 2306
> As of: 2026-08 · Verified: 2026-08-18 · Status: available

## Where do I go to learn GECX formally?

The main public learning path is **Gemini Enterprise for Customer Experience** at
`skills.google/paths/3180`, which teaches transforming customer service using GECX. Two named
courses inside it are **Architect Gemini Enterprise for Customer Experience** (designing, building
and maintaining a GECX solution) and **Conversational AI and its Engagement Framework** (how
contact centres evolved, where generative AI takes them, and the core building blocks of GECX).
There is also an **Introduction to Gemini Enterprise** course covering the parent platform.

## The partner learning paths, and who each is for

Five role-specific paths are published on **Google Skills for Partners**, and they map cleanly onto
the components — which makes them a useful way to staff a delivery team:

**CX Agent Studio Foundations** (`partner.skills.google/paths/522`) equips conversational designers
and builders to design, build, and test multi-agent, multimodal CX agents. This is the starting
point for a build team.

**Production-Ready CX Agents** (`partner.skills.google/paths/523`) covers optimising, testing,
evaluating and deploying CX agents. This is the path that maps to the evaluation framework and the
deployment surfaces, and it is the one most often skipped — which is why pilots stall before
production.

**Conversational Agents, Tools and Webhooks** (`partner.skills.google/paths/2306`) is the
integration-engineering path, matching the tool types and backend connectivity.

**Agent Assist** (`partner.skills.google/paths/521`) covers the human-agent assistance component.

**Customer Experience Insights (CX Insights)** (`partner.skills.google/paths/484`) covers the
analytics component.

## How to sequence training for a delivery team

Start everyone on **Conversational AI and its Engagement Framework** for shared vocabulary, because
the terminology break from Dialogflow is the main source of early confusion. Put designers and
builders through **CX Agent Studio Foundations**, then **Production-Ready CX Agents** before any
production commitment. Put integration engineers through **Conversational Agents, Tools and
Webhooks**. Put the solution architect through **Architect Gemini Enterprise for CX**. Add **Agent
Assist** and **CX Insights** for whoever owns those components — and note that if the engagement
starts with the Agent Assist overlay, that path comes first, not last.

## A note on certification status

These are learning paths, and this research did not confirm the existence of a distinct GECX
certification exam or badge separate from path completion. Do not claim a named GECX certification
without verifying it on Google Skills, since path completion and certification are different
credentials and partners are often asked specifically about the latter.
